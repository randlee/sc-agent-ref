# Sprint r-4 — pins, allocator, released binaries (D8, D13 kinds sentence)

## Outcome

The pin, allocator and second-binary decisions have an ADR (ADR-SAG-0023) and
the manifests match it. Library crates use caret ranges, mimalloc and clap are
optional deps of the two binary crates behind the default `cli` feature, the
CI workflow proves the library builds without mimalloc, and ADR-SAG-0017 names
both released binaries with per-channel coverage. ADR-SAG-0016's version text
and ADR-SAG-0005's extractor-kinds sentence are corrected.

**Why wave 1, parallel with r-1:** ADR text plus manifests. r-4 edits no
`main.rs`: `[[bin]] required-features = ["cli"]` compiles each binary only
when `cli` (and so `dep:mimalloc`) is enabled, so the existing unconditional
`#[global_allocator]` stays valid; both `main.rs` files belong to r-1 in
wave 1. r-1 owns no `Cargo.toml` outside `sc-agent-types`, except deleting the
root `sc-observability-types` line. **Merge order:** r-1 merges first; r-4
rebases onto it before its final validation, because `check-exact-pins.sh`
fails on the `sc-observability-types = "=1.5.0"` entry, which is not on the
ADR-SAG-0023 list and which r-1 deletes. r-4 adds `clap` as an optional
dependency now (unused until r-3c/r-3b) so the wave-2 and wave-4 parser
sprints change no manifest that r-3 also edits.

- **`sc-observability-types` ownership record** (QA-001), resolved. r-4
  kept the record until the dependency was gone; r-1 deleted the record
  with the dependency, and the merge keeps that deletion. r-4 no longer
  deletes it.
- **Warm cargo cache for offline tree tests.** r-1's
  `crates/sc-agent-types/tests/features.rs` runs `cargo tree --locked
  --offline --target all`, so every platform's crates in `Cargo.lock` must
  already be downloaded; adding `clap` brought in platform-only crates, so
  the `test` and `coverage` jobs run `cargo fetch --locked` (no `--target`)
  before their test steps.
- **CLI tests cannot be skipped silently** (FTQ-002). CI job `features` runs
  `cargo test -p sc-treesitter --test cli --features cli` and the same for
  `sc-ai`; cargo fails if the target or the feature is renamed or dropped.
  The skip of `tests/cli.rs` in the `cargo hack --each-feature` cells
  without `cli` is deliberate (`required-features = ["cli"]`). That sentence
  belongs in `docs/development/ci.md`, which is outside r-4's
  `owned_paths`, so it is recorded here and in the PR body instead.
- **Frontmatter** (REQ-QA-R4-003, REQ-QA-R4-004). REQ-SAG-0135 is listed
  under `constrained_by` (r-4 adds optional `clap` and its ownership record;
  r-3b closes the requirement), and `Cargo.lock` is an owned derived file.
- **`tree-sitter` pin form** (RBP minor), declined. The inline-table form
  `tree-sitter = { version = "=0.27.1" }` stays: the unit test
  `extract::tests::pinned_grammar_versions_match_cargo_toml`
