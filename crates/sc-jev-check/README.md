# sc-jev-check

Jev check facade for the sc-agent workspace.

It loads `check.toml`, runs extractors, manages sessions, and exposes `run_check`. `sc-ai` and the `sc-jev-py` Python wheel both call it.

Part of the [sc-agent](https://github.com/randlee/sc-agent) workspace. See the
repository `docs/` for architecture and requirements. Licensed under MIT.
