# sc-treesitter

Tree-sitter producer of `sc/subjects/1` documents, as a library and the `sc-treesitter` CLI.

Python and Rust grammars are on by default (features `python`, `rust`). Install the CLI with `cargo install sc-treesitter --locked`.

Part of the [sc-agent](https://github.com/randlee/sc-agent) workspace. See the
repository `docs/` for architecture and requirements. Licensed under MIT.
